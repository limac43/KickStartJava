# KickStartJava
# 📅 Agenda Semanal com Matrizes em Java

Projeto prático desenvolvido em Java para gerenciar e registrar compromissos ao longo dos 5 dias úteis da semana, aplicando conceitos de estruturas de dados multidimensionais (matrizes).

---

## 🎯 Sobre o Projeto

O objetivo principal desta aplicação é consolidar a manipulação de matrizes bidimensionais na linguagem Java, simulando uma grade semanal de horários e tarefas diretamente no console.

### 💡 Conceitos Aplicados
* Manipulação de matrizes bidimensionais (`String[][]` / `Object[][]`)
* Estruturas de repetição (`for`, `while`) para iteração em linhas e colunas
* Estruturas condicionais para validação de entrada de dados
* Leitura de dados do terminal (`Scanner`)
* Organização de código em pacotes Java

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17+)
* **IDE:** IntelliJ IDEA
* **Controle de Versão:** Git & GitHub

---

## 🚀 Funcionalidades

- [x] Cadastro de tarefas por dia da semana (Segunda a Sexta).
- [x] Agendamento por blocos de horários.
- [x] Visualização completa da grade semanal de compromissos.
- [x] Validação de horários/dias preenchidos.
